# Samples Directory

This directory contains clean, standalone, public reference samples demonstrating how to structure inputs for the automation pipeline:

- `samples/beamer/`: Sample multi-slide markdown presentations (`sample_presentation.md`).
- `samples/templates/`: Reusable presentation templates (`modern_clean.tex`).
- `samples/thesis/`: Minimal clean thesis skeleton (`sample_thesis.tex`).

You can test the entire pipeline with these samples at any time by running:
```bash
uv run beamer demo
```
